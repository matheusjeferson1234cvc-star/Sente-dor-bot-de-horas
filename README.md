**Central de Horas** é o primeiro módulo da plataforma NERO. O nome público da marca foi atualizado no site; nomes internos de API, banco, variáveis e domínio permanecem intactos para preservar integrações.

# Central de Horas v5.8.4

Painéis de bate-ponto e justificativas em configurações separadas, com título, descrição e GIF independentes.
A API verifica a permissão Discord Administrator (bit 8); não concede edição pelo nome do cargo.
A tela permite visualizar as configurações em modo consulta e diagnosticar o motivo da falta de edição.
Atualize também o bot v3.7.2 para o painel de justificativas receber o visual editado no site.
O primeiro envio de cada painel ainda requer o comando Discord correspondente.

Veja **INSTALAR-V5.8.4.txt**. Nenhum SQL novo é necessário se `bot_config` já está configurado.
