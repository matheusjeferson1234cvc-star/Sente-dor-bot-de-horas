# Nero Recrutamento · Fundação segura

Projeto Vercel separado do site principal, compartilhando somente a identidade do servidor por ID Discord.
A página pública está **fechada por padrão** e não recebe candidaturas nem provas até a implementação de verificação de identidade, avaliação, revisão e auditoria. Não confundir esta publicação inicial com um sistema completo de recrutamento.

## Link por servidor

`https://nero-recrutamento.vercel.app/?guild=ID_DO_SERVIDOR`

## Ambiente Vercel (somente backend)

- SUPABASE_URL
- SUPABASE_SECRET_KEY
- DISCORD_BOT_TOKEN (opcional para o ícone do servidor)

Credenciais permanecem apenas no Vercel; nunca adicionar segredos ao repositório.
